After the event (T+2), each member runs the `teardown` stage in their own repo, the team lead runs the full teardown last, and an admin then removes the pipeline identity. Run commands from `factory/`.

## Run the teardown stage

**In your own repo (member):**

```bash
gh workflow run platform.yml -f stage=teardown
```

- A **member's** run removes that member's datacenter, spoke and archetype.
- **In the team lead's repo**, add `-f members=<your index>` to remove only that member:

  ```bash
  gh workflow run platform.yml -f stage=teardown -f members=<your index>
  ```

- **Team lead's full teardown at T+2** removes every member first, then the team's foundation:

  ```bash
  gh workflow run platform.yml -f stage=teardown -f members=all -f confirm-team-teardown=true
  ```

Unless the event owner will reuse the tenant, add `-f include-management=true` to the full teardown command. It also deletes `rg-management` and `id-sqlmi-directory`, so a later event needs the Graph grant again.

:::caution
After C5, the member `teardown` stage removes the archetype, including the SQL Managed Instance, which takes hours to provision again. Never run it, or `teardown` followed by a new `member` run, after C5 without asking your coach first.
:::

Done when the run is green.

## Remove the pipeline identity

The workflow can't remove its own identity, so an admin runs this script when the stage ends. It removes the identity's roles, the identity, `rg-cicd`, the GitHub environment and the pipeline's repository variables, then checks each is gone.

```powershell
./scripts/Remove-PlatformPipeline.ps1                    # team lead
./scripts/Remove-PlatformPipeline.ps1 -Profile Member    # member
```

Run the lead variant in the lead's repo and the member variant in each member's repo.

Done when the script reports every item as gone.

## What stays

- The Graph grant stays in the tenant unless an admin removes it.
- The pipeline never removes human access. Whoever granted roles to people (Owner on a subscription, collaborators on a repo) removes them.
