After the event (T+2), members can remove their own scopes in their repos. The team lead then runs the full `teardown` in the lead repo, and an admin removes the pipeline identity. Run commands from `factory/`.

See [Cost](../../reference/cost/) for when the foundation, datacenter and archetype charges stop.

## Run the `teardown` stage

**In your own repo (member profile):** this removes only your member scope.

```bash
gh workflow run platform.yml -f stage=teardown
```

**In the team lead's repo at T+2:** remove every member, then the team's foundation. Add `-f include-management=true` unless the event owner will reuse the tenant; a later event then needs the Graph grant again.

```bash
gh workflow run platform.yml -f stage=teardown -f members=all -f confirm-team-teardown=true -f include-management=true
```

If the tenant will be reused, omit `-f include-management=true`.

**In the team lead's repo, for one member only:** add their index and omit the team confirmation:

```bash
gh workflow run platform.yml -f stage=teardown -f members=<your index>
```

Before T+2, never run an unfiltered team `teardown` in the lead repo.

`include-management` also deletes `rg-management` and `id-sqlmi-directory`.

:::caution
After C5, the member `teardown` stage removes the archetype, including the SQL Managed Instance, which takes hours to provision again. Do not start over after C5; ask the event owner for a coach repair.
:::

Done when the run is green.

## Remove the pipeline identity

The workflow can't remove its own identity, so an admin runs this script when the stage ends. It removes the identity's roles, the identity, `rg-cicd`, the GitHub environment and the pipeline's repository variables, then checks each is gone.

```powershell
./scripts/Remove-PlatformPipeline.ps1                    # team lead
./scripts/Remove-PlatformPipeline.ps1 -Profile Member    # member
```

Run the lead variant in the lead's repo and the member variant in each member's repo.

Done when the script reports every item as gone.

## What stays

- The Graph grant stays in the tenant unless an admin removes it.
- The pipeline never removes human access. Whoever granted roles to people (Owner on a subscription, collaborators on a repo) removes them.
