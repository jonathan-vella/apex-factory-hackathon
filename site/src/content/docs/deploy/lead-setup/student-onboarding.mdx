**Who:** **Every student** in a lead-provisioned event.
**When:** Before Day 1 kickoff (allow **20 to 30 minutes** once your team lead sends your private Handoff Card).

Your team lead has already deployed the shared Azure landing zone, your simulated datacenter (`vm-app01` and `vm-dev01`), Azure Arc, and your spoke network—and created your private student repository (`<org>/<your-repo>`, for example `<org>/<event>-student-01`). You do **not** create any GitHub repository, install local WSL/Docker/Dev Containers, or run any GitHub Actions pipeline. Every challenge (`C1` to `C10`) runs inside `vm-dev01` in a single clone (`C:\src\<your-repo>` on `main`). Complete the three onboarding steps below so your workstation and Copilot tools are ready before Day 1 starts at 08:30.

If anything blocks you, contact your **designated team lead** first.

## 1. Share your GitHub username and accept your repository invitation

<Steps>

1. **Send your GitHub username** to your team lead if you haven't already, and receive your private **Handoff Card** (`member-<index>.md`). Keep the values on that card private—never paste subscription IDs, tenant IDs, or lab passwords into issues, commits, or public chats.

2. **Accept your collaborator invitation.** Open the GitHub invitation email or go directly to:

   ```text
   https://github.com/<org>/<your-repo>/invitations
   ```

   Select **Accept invitation**. Until you accept, GitHub hides private repositories and `git clone` returns `404 Not Found`.

</Steps>

Done when `https://github.com/<org>/<your-repo>` opens in your browser and shows `factory/`, `app/ContosoUniversity/` and `infra/bicep/university/` on `main`.

## 2. Connect to `vm-dev01` through Bastion and set up your workspace

<VmDev01Setup pathMode="lead-provisioned" />

### Check your setup on `vm-dev01`

Run in **PowerShell 7 (`pwsh`)** on `vm-dev01`:

```powershell
gh auth status
git config --global user.name
az account show --query name -o tsv
[Environment]::GetEnvironmentVariable('AZURE_TOKEN_CREDENTIALS', 'User')
git -C C:\src\<your-repo> branch --show-current
git -C C:\src\<your-repo> status --short --ignored -- app .github/upgrades
Get-Content C:\src\<your-repo>\factory\.local\settings.json
```

Done when GitHub is signed in, git has your name, Azure shows your workload subscription, `AZURE_TOKEN_CREDENTIALS` is `AzureCliCredential`, `C:\src\<your-repo>` is on `main`, `settings.json` has your `suffix` and `memberIndex`, and the `git status` command prints nothing. Keep `vm-dev01` running during the event—never shut down or deallocate it while hacking.

## 3. Confirm readiness on `main`

Your team lead already pushed `factory/evidence/readiness/test-datacenter.txt` to your student repository in Step 3:

1. In `C:\src\<your-repo>` on `vm-dev01`, confirm `factory/evidence/readiness/test-datacenter.txt` is present with `PASS` results.
2. In the Azure portal, open **Azure Arc** > **SQL Server instances**, select the instance on `vm-app01`, open **Migration** > **Assessments** (choose **Run assessment** if not yet run), and confirm the **Azure SQL Managed Instance** readiness report is available for C3.

Done when `factory/evidence/readiness/test-datacenter.txt` is present on `main` and VS Code + Copilot Chat are ready on `vm-dev01`. Let your team lead know you are ready!

Next: join the 30-minute hackathon introduction at **08:30 on Day 1**, then start [C1: Define the opportunity](/challenges/c01-define-the-opportunity/) at **09:00**.
