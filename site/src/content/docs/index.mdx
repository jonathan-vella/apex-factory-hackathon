        <div class="scenario-panel__label">Starting point</div>
        <p>Contoso University runs its student system on ASP.NET MVC and .NET Framework 4.8 on IIS and SQL Server in its own datacenter. It wants to move to Azure and modernize so its data is ready for future AI use cases.</p>
        <dl class="shift">
          <div><dt>App</dt><dd>.NET Framework 4.8 <b>to</b> .NET 10 and ASP.NET Core MVC</dd></div>
          <div><dt>Hosting</dt><dd>IIS on <code>vm-app01</code> <b>to</b> a container image on App Service for Linux</dd></div>
          <div><dt>Database</dt><dd>SQL Server <b>to</b> Azure SQL Managed Instance</dd></div>
          <div><dt>Messaging</dt><dd>MSMQ <b>to</b> Azure Service Bus</dd></div>
        </dl>
      </div>
      <div class="scenario-panel scenario-panel--tasks">
        <div class="scenario-panel__label">What the team does</div>
        <ul class="scenario-checklist">
          <li>Build a secure foundation.</li>
          <li>Assess with GitHub Copilot and Azure Arc.</li>
          <li>Adapt the CoE archetype with APEX and deploy it with azd.</li>
          <li>Modernize the app and migrate data to SQL Managed Instance.</li>
          <li>Optimize the database and package reusable assets.</li>
        </ul>
      </div>
    </div>
  </div>
