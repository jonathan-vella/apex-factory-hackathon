Pre-work is [Prerequisites](../prerequisites/) (accounts, tools, your repo with the kit imported) followed by [C0: Ready to hack](../../challenges/c00-ready-to-hack/). T-14 is 14 days before day one of the event and T-3 is 3 days before it. Complete Prerequisites and C0's preflight by T-14. By T-3: the datacenter is deployed, `Test-Datacenter.ps1` passes for you (run before Arc onboarding), `vm-app01` is connected to Azure Arc, your first migration assessment has run, the legacy app is healthy, and you have a fully set up `vm-dev01` (C0 task 7), with Copilot working in VS Code. The [event overview](../event-overview/#pre-work) has both gates.

If you're the platform lead, you still complete your own C0 like every other member. Enter your shared services subscription when `Initialize-Settings.ps1` asks (see Prerequisites), so preflight also checks your Tenant Root rights at T-14. The shared services work starts in C2.
