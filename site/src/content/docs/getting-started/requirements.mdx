This page lists what you need before you deploy anything. Checking it takes about 30 minutes, plus any time your organization needs to grant access. Ask for access early: that is the slow part. If something blocks you before day one, ask your team lead; they can escalate to the event owner.

## Team size

A team is 3 to 5 people, including the team lead. Each team has:

- one Microsoft Entra tenant,
- one shared services subscription, which the team lead holds,
- one workload subscription per member, the team lead included.

So a team of five has six subscriptions. The team lead is a colleague your team nominates. They are also a member, and they do every member challenge on their own workload subscription.

## Accounts and access

| What | Requirement |
| --- | --- |
| GitHub | A personal account in your partner's GitHub org, with GitHub Copilot enabled. Agent mode and the Upgrade agent must be allowed by policy. |
| GitHub Actions | Actions minutes for private repos on your account or org. The pipeline runs in your private repo, so a failed payment or a spending limit of zero blocks every run. Check **Settings** > **Billing and plans** before the event. |
| Azure subscription | One paid workload subscription per member, in your team's Microsoft Entra tenant. Your partner organization supplies it; ask your team lead if you need help identifying your tenant. Trial, Azure Pass and sponsorship subscriptions are not supported. Preflight doesn't check the offer type, so confirm in the Azure portal that yours is paid. |
| Azure role | An unconditional **Owner** assignment on your workload subscription (direct, inherited or through a group). If it's eligible through Privileged Identity Management (PIM), [activate it first](https://learn.microsoft.com/entra/id-governance/privileged-identity-management/pim-resource-roles-activate-your-roles). Contributor doesn't pass. If your organization blocks Owner, ask your team lead to escalate to the event owner well before T-14. |
| MFA | Registered for your Azure identity. Set it up at [aka.ms/mysecurityinfo](https://aka.ms/mysecurityinfo) if you haven't. |
| Region quota | Enough regional vCPU quota in your event's region (`swedencentral` unless told otherwise) for two Standard_D8as_v6 VMs (16 vCPU in total), plus quota for the archetype's SQL Managed Instance and App Service in C5. Preflight doesn't check quota. To look it up, open your subscription in the Azure portal, choose **Usage + quotas** and filter by your event's region. If quota is short, ask your team lead to escalate to the event owner. |
| Team lead only | A **second** subscription (shared services) plus Owner at Tenant Root, the top management group of your tenant. A Global Administrator has to [elevate access](https://learn.microsoft.com/azure/role-based-access-control/elevate-access-global-admin) for that, so ask early: the team lead deploys the foundation at T-7. The team lead also books a Privileged Role Administrator for the T-7 Graph grant; that role holder needs PowerShell 7, Azure CLI and Reader on the shared services subscription. If you can't find a role holder, escalate to the event owner. You are also a member, so you still need your own workload subscription. |

Done when you can sign in to the Azure portal, see your workload subscription, and the role shown for it is Owner.

<details>
<summary>Why each member needs their own subscription</summary>

Every member's datacenter, network and archetype live in their own workload subscription, so members can work in parallel without affecting each other. The team shares one hub network and one set of central policies in the shared services subscription. The [ALZ-lite guide](../../guides/alz-lite/) explains the model.

</details>

## Tools

You only need a few host tools to open the dev container. Everything else, including the Azure CLI, is inside it.

| Tool | Why | Verify |
| --- | --- | --- |
| [VS Code](https://code.visualstudio.com/) 1.100 or newer | The editor, agent mode, and **Git: Clone** | `code --version` |
| [Docker Desktop](https://www.docker.com/products/docker-desktop/) | Runs the dev container | `docker version` |
| [Git](https://git-scm.com/downloads) | VS Code's **Git: Clone** needs it | `git --version` |
| VS Code extensions: Dev Containers (`ms-vscode-remote.remote-containers`) and GitHub Copilot Chat (`github.copilot-chat`) | Open the container; Copilot sign-in | `code --list-extensions` |

```powershell
code --install-extension ms-vscode-remote.remote-containers
code --install-extension github.copilot-chat
```

Done when each verify command prints a version or lists the extensions.

<details>
<summary>Windows 11 from scratch</summary>

<Steps>

1. Install [WSL](https://learn.microsoft.com/windows/wsl/install) with Ubuntu (`wsl --install`), then restart. Open **Ubuntu** from the Start menu once: the first launch asks you to create a Linux user name and password.
2. Install Docker Desktop and turn on **Use the WSL 2 based engine**. Then open Docker Desktop **Settings** > **Resources** > **WSL integration** and switch on **Ubuntu**. Without this, the dev container can't find Docker from Ubuntu.
3. Install VS Code, the two extensions above, and the **WSL** extension (`ms-vscode-remote.remote-wsl`).
4. You clone your repo from inside Ubuntu, not into a Windows folder. The dev container is much faster that way, and line endings stay correct.

</Steps>

</details>

## Network

Allow outbound HTTPS to these hosts:

- **GitHub and Copilot:** `github.com`, `api.github.com`, `codeload.github.com`, `*.githubusercontent.com`, `api.githubcopilot.com`.
- **Azure and Microsoft:** `*.azure.com`, `*.microsoft.com`, `login.microsoftonline.com`, `learn.microsoft.com`.
- **Docker Hub:** `docker.io`, `registry-1.docker.io`.
- **The dev container:** `ghcr.io` (its features come from there), `mcr.microsoft.com` (its base image, covered by `*.microsoft.com`) and `packagefeedproxy.microsoft.io` (its Node.js and Python package proxy).
- **VS Code:** `marketplace.visualstudio.com` for extensions.

Done when you can open each host in a browser or with `curl` from the network you will work on.
