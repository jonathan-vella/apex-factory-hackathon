## How to read this register

- **ID prefix** shows which part of the site the finding came from: `START` Home, Getting Started, About; `DEP` Deploy section, scripts, workflows, Bicep; `CHA` Challenges overview, C1 to C5; `CHB` C6 to C10; `GDE` Guides and Prompts; `CRF` Coach and Reference; `LEAD` Lead reviewer: live site, pager, search, link graph.
- **Sev:** P0 blocks the event or a persona's journey · P1 likely to cause failure, rework or confusion · P2 quality issue · P3 polish.
- **Type:** D is a defect, S a suggestion. **Effort:** S under an hour, M under a day, L more than a day.
- **Theme** groups findings by root cause; each theme is one GitHub issue (T01 to T10).
- **Evidence** is a short verbatim quote from the page or the repo file named in **Source**. "Needs owner confirmation" marks a point the reviewers couldn't settle from the repo or Microsoft Learn.
